Student Management System (C)

About the Project

A beginner-friendly Student Management System developed using the C programming language. This project allows users to enter and display student information, including roll numbers, names, and marks.

Features

- Enter student details
- Store student records during program execution
- Display student information
- Display student marks
- Handle multiple student records

Technologies Used

- C Programming
- Structures
- Arrays
- Loops
- Conditional Statements

How to Run

1. Download or clone this repository.
2. Open the ".c" file in a C compiler.
3. Compile and run the program.
4. Enter the requested student information.

Purpose

Created as an academic project to practice fundamental C programming concepts and basic data handling.
